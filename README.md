# Grim Legends

## Description
**Grim Legends** is an action-packed video game that immerses players in a dark fantasy world overrun by evil skeletons and powerful wizards. Designed for controller-based gameplay, the game features intuitive controls—using Triangle, Square, and Circle for different attack styles, and X for jumping. The story begins with your home village under siege, and it’s up to you to clear out nearby enemies and reclaim the land. Players must adapt to combat styles as wizards launch ranged lightning spells while skeletons engage in close-quarters combat.
